## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Running Build

```bash
npm run build
# or
yarn build
# or
pnpm build
```

And after success, start build by using this command:

```bash
npm run start
# or
yarn start
```

## Test

```bash
npm run test
# or
yarn test
```
